# 泰国杰特宁三代试管婴儿费用多少？

> 更新时间：2026-09-11 (UTC+8)

在东南亚辅助生殖领域，泰国杰特宁医院（Jetanin IVF）以其先进的技术、严谨的医疗团队和较高的成功率，成为许多不孕不育夫妇的选择。作为泰国较早开展第三代试管婴儿（PGD/PGS技术）的机构之一，其费用构成透明且细化，本文将结合医疗流程，拆解三代试管婴儿的核心费用项目及大致范围，帮助读者建立清晰认知。

　　一、医院背景：为何选择杰特宁？

　　杰特宁医院成立于2000年，总部位于曼谷，是东南亚知名的生殖医学中心，尤其擅长第三代试管婴儿技术（PGD/PGS基因筛查诊断）。医院配备国际先进的实验室设备，医生团队经验丰富，成功率在东南亚地区处于领-先水平（据其官网信息，50岁以下女性新鲜周期成功率约60%-70%）。其核心优势在于通过PGS/PGD技术筛选健康胚胎，降低遗传疾病风险，提高妊娠率，尤其适合有遗传病史或高龄女性。泰国杰特宁医院网址：jetenin.com

　　二、三代试管婴儿核心费用构成（以基础套餐为例）

　　泰国试管婴儿费用通常以“基础套餐”为框架，涵盖医疗流程中的核心环节，具体费用因个体情况（年龄、身体状况、治疗方案）略有差异，以下为大致范围（以2024年汇率1人民币≈20泰铢计算，费用单位为人民币）：

　　1. 术前检查费用：约5000-8000元

　　术前检查是确保治疗安全的基础，需男女双方完成全面体检。女性检查项目包括性激素六项、AMH（卵巢储备功能）、子宫B超、传染病筛查（乙肝、丙肝、HIV等）、输卵管造影等；男性检查包括精液分析、传染病筛查等。

　　费用说明：基础检查套餐约2000-3000元（泰铢1-1.5万），若存在特殊情况（如卵巢功能较差需额外检查），费用可能增至5000-8000元。

　　2. 促排卵药物与取卵手术：约2.5万-5万元

　　促排卵是获取多个成熟卵子的关键，药物选择直接影响费用。杰特宁医院常用进口促排卵药（如果纳芬、普丽康等），剂量和种类需根据女性卵巢功能调整（年轻、卵巢功能好者用药量少，反之需增加剂量）。

　　- 药物费用：基础促排卵药约1.5万-3万元（泰铢7.5万-15万），若使用进口药物，费用可能达3.5万-5万元。

　　- 取卵手术：包含在促排卵环节中，通过阴道穿刺术取出卵子，费用约5000-1万元（泰铢2.5万-5万），需麻醉，无额外麻醉费。

　　3. 胚胎培养与PGD/PGS基因筛查：约3万-6万元

　　取卵后需与精子结合形成胚胎（若需单精子注射ICSI，费用增加约5000元），随后进行第三代试管婴儿的核心——PGD/PGS基因筛查。

　　- 胚胎培养：将受精卵培养至囊胚阶段（第5天），费用约1万-2万元（泰铢5万-10万），若仅培养至卵裂期（第3天），费用可降至5000-1万元。

　　- PGD/PGS筛查：检测胚胎的23对染色体（PGS，胚胎植入前遗传学筛查）或特定基因（PGD，胚胎植入前遗传学诊断），每枚囊胚筛查费用约1.5万-3万元（泰铢7.5万-15万）。若筛查3枚胚胎，费用约4.5万-9万元。

　　4. 胚胎移植手术：约1万-2万元

　　移植分“新鲜移植”和“冷冻移植”，费用略有差异：

　　- 新鲜移植：取卵后3-5天进行，费用约8000-1.5万元（泰铢4万-7.5万），包含一次移植手术及基础黄体支持药物。

　　- 冷冻移植：若选择冷冻胚胎，需额外支付冷冻费（约5000元/年），移植时费用与新鲜移植类似。

　　注意：杰特宁医院通常包含1次移植，若需多次移植（如未成功需二次移植），每次额外收取约5000-1万元。

　　5. 附加服务与其他费用：约1万-3万元

　　住宿与翻译：医院不强制提供住宿，但可协助安排，住宿费用约500-1000元/天（单人房），翻译服务（中泰双语）约1万-2万元（全程陪同）。

　　术后药物：移植后需使用黄体酮类药物维持黄体功能，费用约3000-5000元（泰铢1.5万-2.5万），可在当地药店购买，费用更低。

　　其他：若存在特殊情况（如卵巢过度刺激综合征需住院），住院费约1万-2万元。

　　三、总费用范围与影响因素

　　综合上述项目，泰国杰特宁医院三代试管婴儿的基础费用（不含附加服务）约10万-15万元人民币。

　　关键影响因素包括：

　　- 年龄：年龄越大（如35岁以上），促排卵药用量和周期可能增加，费用上升；

　　- 卵巢功能：卵巢功能差者需更多药物或更长周期，费用增加；

　　- 胚胎数量：需筛查的胚胎越多，PGS费用越高；

　　- 附加服务：翻译、住宿等非医疗费用可根据需求调整。

　　四、注意事项：避免隐形消费

　　费用透明化：杰特宁医院官网会公示基础套餐费用，建议提前邮件或微信咨询（支持中文沟通），明确是否包含所有医疗环节（如是否含翻译、住宿）；

　　个性化方案：医生会根据个体情况制定方案，如卵巢功能差者可能需长方案，费用与短方案不同，需提前确认；

　　成功率与费用的关系：三代试管的费用主要与技术复杂度相关，成功率（如50岁以下女性新鲜周期成功率约60%-70%）需结合医院实际数据，避免盲目追求低价。

　　总结

　　泰国杰特宁医院的三代试管婴儿费用透明且细化，核心费用集中在术前检查、促排卵、胚胎培养与基因筛查、移植四大环节，总费用随个体情况波动。建议患者提前与医院沟通，明确自身需求（如是否需要冷冻胚胎、翻译服务），并通过正规渠道获取新报价，以确保治疗过程顺利可控。
