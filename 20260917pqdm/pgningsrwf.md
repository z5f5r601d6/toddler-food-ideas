# 试管建档前凝血五项是检查什么的？

> 更新时间：2026-09-17 (UTC+8)

因为子宫内膜异位症一直没怀上宝宝，现在是宫腔镜术后一年了，想再试试试管婴儿助孕，从朋友那里大致了解了一下试管婴儿的流程，说是第一次会做一些建档前的常规检查，比如性激素6项，凝血五项，甲功，肝功等等，但我之前没听说过凝血五项，不知道这个主要是检查什么的呢？ 
查看全部内容

试管建档前需要抽血检查凝血五项，凝血五项包括凝血酶原时间（PT）、部分活化凝血活酶时间（APTT）、凝血酶时间（TT）、纤维蛋白原（FIB）以及D-二聚体，其检查的目的和意义在于观察患者是否有高凝状态，判断患者是否存在血液系统疾病，帮助医院制定试管方案，保证试管婴儿进程的顺利推进。

凝血五项不需要空腹，建议是在每天早上的6:00-9:00做，只要到医院抽血就好，检查2个小时左右出结果，结果单上会包含5个指标，具体代表的意义及正常参考值如下：

- 1. 凝血酶原时间（PT），正常值为10.5-14秒，主要反映外源性凝血途径的指标；
- 2. 部分活化凝血活酶时间（APTT），正常值为21-34秒，其主要反映内源性凝血途径的指标；
- 3. 凝血酶时间（TT），正常值为14-20秒，它是反映纤维蛋白原浓度是否正常的指标；
- 4. 纤维蛋白原（FIB），正常成人纤维蛋白的浓度正常值为2-4g/L；
- 5. D-二聚体，反映人体是否有凝血过程的指标，正常人是阴性，阳性说明机体有凝血的情况。
凝血五项异常会影响试管婴儿手术的顺利进行，不仅容易导致血栓形成，即使胚胎着床成功了也可能因为子宫供血不畅导致胎停或妊娠并发症的发生，这也是试管婴儿做凝血检查的原因所在，所以在试管建档前或是移植后检查都是很有必要的。
