# 不孕不育防治“十一问”：早了解、早干预、早好孕（上篇）

> 更新时间：2026-09-16 (UTC+8)

**引言：生育问题的挑战**

不孕（育）症是一种低生育力状态，指一对配偶未采取避孕措施，有规律性生活至少12个月未获得妊娠，女性称为不孕症，男性则称为不育症。随着社会的快速发展和生活方式以及环境的变迁，育龄人群的生殖健康正面临越来越多的负面影响。全球每年新增约200万对不孕不育夫妇。根据我国生殖健康调查的数据，中国不孕症的患病率从2007 年的11.9%上升到2020年的17.6%。目前我国约有3300万对育龄夫妇面临不孕问题的困扰。不孕不育与肿瘤、心脑血管疾病并称为严重危害人类健康的三大疾病。生育能力下降现状已成为全社会面临的重要问题和严峻挑战。哪些不良生活习惯、肥胖、环境污染及潜在的暴露会增加不孕不育的风险呢？根据《育龄人群不孕不育防治临床实践指南（2024）》建议如下。

**哪些不良生活习惯会增加不孕不育风险？**

**（1）吸烟及暴露于二手烟**

吸烟及暴露于二手烟均会增加育龄人群不孕不育风险。建议育龄人群孕前 3个月戒烟，并尽量避免接触二手烟，戒烟困难者向专职医疗人员寻求咨询与帮助。

**（2）酒精及咖啡因饮品**

大量饮酒显著降低生育能力，大剂量咖啡因可能对健康及生育力存在影响。推荐育龄人群孕前3个月限制含酒精饮品的摄入量（每天酒精摄入量不要超过12g，相当于饮用53°白酒28ml、12°葡萄酒125mL或5°啤酒300 ml）。建议育龄人群孕前3个月限制含咖啡因饮品的摄入量（每天咖啡因摄入量不要超过400mg）。

**（3）不良饮食习惯**

促炎饮食包括精制碳水化合物、含糖饮料、油炸食品、红肉和加工肉类、人造黄油等，与女性不孕的关系日益密切。推荐育龄人群孕前 3个月调整饮食习惯，避免高脂肪及高碳水化合物饮食，推荐采用均衡健康的饮食模式，优先选择全谷物、新鲜蔬菜、水果、白肉（如鱼、虾、贝类及家禽）、适量的豆类和坚果，并使用橄榄油作为主要食用油，同时减少红肉、加工肉制品和烧烤食品的摄入。

**（4）睡眠问题**

昼夜节律紊乱和睡眠时间不足会增加育龄人群不孕不育风险，推荐育龄人群孕前3个月保持规律且充足的睡眠时间，维持正常昼夜节律。

**肥胖是否会增加不孕不育风险？**

（1）肥胖会增加育龄女性不孕风险，肥胖育龄女性应被告知生育力可能降低。肥胖会增加育龄男性不育风险，降低精液质量。

（2）肥胖对辅助生殖结局有负面影响，接受辅助生殖治疗前的肥胖育龄人群应被告知成功率可能降低。

（3）肥胖女性发生孕产妇和胎儿并发症的风险显著升高，子代出生缺陷（包括先天性心脏病、先天性肾脏和尿路畸形、神经管缺陷、脊柱裂、腭裂、唇腭裂、肛门直肠闭锁、脑积水和肢体短缩畸形等）风险增加，子代发生精神障碍性疾病（包括注意力缺陷/多动障碍、孤独症谱系障碍、认知/智力迟缓和行为异常等）、哮喘和白血病的风险增加。

（4）推荐肥胖育龄人群在孕前减重；初步减重5%～10%（3～10 kg）可能达到改善生育力的目的。生活方式干预是肥胖的一线治疗方法，其次为药物辅助治疗，对于病态肥胖或BMI>35kg/m2且同时患有肥胖相关疾病的育龄女性可在以上减重方式失败后尝试采用减重代谢手术，可寻求专科医生指导。

**哪些潜在的环境暴露会增加不孕不育风险？**

（1）大气污染物暴露：推荐育龄人群采取适当防护措施（如佩戴口罩、雾霾天气时减少非必要室外活动、室内空气净化等）以减少大气污染物暴露。

（2）环境内分泌干扰物：推荐育龄人群尽量减少含有双酚A（BPA）的塑料制品暴露，尽量选择明确标注“不含双酚A”的塑料制品；尽量选择不含三氯生（TCS）的消毒剂、牙膏、洗发水等生活用品。

（3）全氟辛酸（PFOA）和全氟辛烷磺酸盐（PFOS）：推荐育龄女性尽量减少使用含有这些化学物质的不粘锅（特氟龙涂层）、方便食品包装和涂料等产品。

（4）杀虫剂及农药：有机氯类杀虫剂、拟除虫菊酯类农药、有机磷农药暴露会增加育龄人群不孕不育风险，推荐育龄人群加强防护，尽量减少或避免暴露。

**哪些其他潜在暴露会增加不孕不育风险？**

（1）铅、镉：铅、镉暴露会增加育龄人群不孕不育风险，推荐育龄人群加强防护，尽量减少或避免暴露。

（2）高温暴露：高温暴露会增加男性不育和女性不良妊娠结局风险，建议育龄人群加强防护，尽量减少或避免长时间高温暴露。

（3）电离辐射暴露：电离辐射暴露会增加育龄人群不孕不育和不良妊娠结局风险，建议育龄人群加强防护，尽量减少或避免暴露。
